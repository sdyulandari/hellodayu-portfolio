## D. Catatan Pengisian

- Satu sel = satu ikon status. Jangan tulis paragraf di dalam sel matriks.
- Bila **Partial**, detail wajib ada di file platform yang bersangkutan.
- Kolom **Catatan** hanya untuk hal singkat (mis. "hanya via ONVIF", "tanpa audio").
- Sumber kebenaran detail tetap file platform, bukan matriks ini.
