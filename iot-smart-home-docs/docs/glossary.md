# Glosarium

| Istilah | Arti |
|---------|------|
| **IP Camera** | Kamera yang terhubung via jaringan IP. |
| **NVR** | Network Video Recorder — penyimpan & pengelola rekaman kamera IP. |
| **VMS** | Video Management System — software manajemen video multi-kamera. |
| **VMS Heklix** | Produk VMS (command center) kami untuk skala besar. |
| **VMS Cloud** | VMS berbasis cloud untuk manajemen terpusat multi-site. |
| **Eazy Gateway** | Perangkat/perangkat lunak untuk integrasi kamera existing/third-party. |
| **ONVIF** | Standar terbuka untuk interoperabilitas kamera IP. |
| **RTSP** | Protokol streaming video real-time. |
| **PTZ** | Pan-Tilt-Zoom — kontrol gerak & zoom kamera. |
| **Two-way audio** | Komunikasi suara dua arah lewat kamera. |
| **Playback** | Pemutaran ulang rekaman. |
| **Retensi** | Lama durasi rekaman disimpan. |
| **Partial** | Status: didukung dengan batasan. |
| **Roadmap** | Status: fitur dalam rencana pengembangan. |
